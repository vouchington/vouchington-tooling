`vouchington-workflow` 0.14.0 absorbs generic skill mechanics that consumers kept in local copies.
`stacked-prs` explains fast-forwarding the default branch before `gh stack init`. `blackboard`
defines the `sandbox-escalation`, `sandbox-failure`, and `ambiguous-failure` journal blocks.
`github-issue` requires reproducing a new blocker against a refreshed base, treats a stop condition
as a human decision, and sets the `## Files / areas` path rules. `retrospective` gains its budget,
the `compose` field list, and `ci-failures` and `sandbox-audit` references; the sandbox audit
points at the `escalations` transcript facts. `retrospective-distill` gains partition bounds,
indivisible session groups, remote-ancestry verification, and an issue-body template.
